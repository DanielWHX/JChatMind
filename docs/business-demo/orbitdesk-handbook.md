# OrbitDesk plans, pricing, team sizes, CSV exports and Slack alerts
OrbitDesk is a fictional SaaS product used only for this JChatMind portfolio demonstration. These are sample policies, not a real company's offer.
OrbitDesk helps small teams track customer requests.
The Starter plan costs USD 9 per user per month and supports 1 to 5 users. It includes a shared inbox but does not include CSV exports or Slack alerts.
The Team plan costs USD 18 per user per month, requires at least 5 users, and includes a shared inbox, CSV exports and Slack alerts. There is no maximum team size specified in this sample plan.
Monthly subscription cost equals the number of users multiplied by the plan's per-user price. Prices exclude taxes; this demo does not calculate taxes. There are no stated discounts or setup fees.
When a customer asks about next month's user count, calculate next month's full monthly cost. Mid-cycle proration is not specified.

# OrbitDesk free trial duration, start date, expiry date and payment card
The free trial lasts 14 calendar days and provides Team plan features.
For this demo, the expiry date is defined as the start date plus 14 days. For example, a trial starting on 2026-01-01 expires on 2026-01-15.
No payment card is required for the trial. A trial ends without automatic payment if the customer has not subscribed.
When asked about a trial starting today, use the real date tool to obtain today's date, then calculate the expiry date. Do not invent the current date.

# OrbitDesk onboarding, CSV import and Slack connection
After creating a workspace, invite teammates, import existing customer requests using a CSV file, and connect Slack alerts from workspace settings.
CSV imports are limited to 5,000 rows per file. Larger imports must be split into multiple files.
Connecting Slack in this demo is a described product workflow, not a live integration available to the JChatMind assistant.
